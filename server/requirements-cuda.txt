# torch is installed SEPARATELY, from the PyTorch CUDA index — never from PyPI.
#
# Why (IP-176 RC2 — this shipped as a real bug):
#   PyPI's win_amd64 torch wheel is ~122 MB and is CPU-ONLY. The CUDA build is
#   ~2.5 GB and exists only on download.pytorch.org. A plain `pip install torch`
#   on Windows therefore yields a torch with no CUDA, the app silently ran on
#   CPU, and users reported "it loads but never generates speech".
#   (On Linux, PyPI's torch pulls the nvidia-* CUDA deps, which is why this was
#   invisible to us locally.)
#
# The launchers (start.sh / start.bat / bootstrap.py) install torch first via:
#   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
# and then assert torch.version.cuda is not None before continuing.
#
